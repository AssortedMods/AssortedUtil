# Assorted Damage Numbers

Damage and healing pop off creatures as numbers, with what caused them beside them: the weapon of a
player's hit, the creature behind a creature's. The number is the damage actually taken, after
armour. Client-side, so it works on any server.

Settings - the source, healing, range and how long a number stays - are in `assorteddamagenumbers-client.toml`.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib). One of the mods built from
[AssortedUtil](https://github.com/AssortedMods/AssortedUtil); see its README for building and
reporting issues.
