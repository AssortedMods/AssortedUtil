# Assorted Item Replacer

When the stack in your hand runs out or your tool breaks, a match from your inventory takes its
place: the same item, with the same enchantments where there is a choice, and never a different
potion. Client-side, so it works on any server. From the Grim Util part of the old
[Grim Pack](https://github.com/grim3212/grim-pack).

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib). One of the mods built from
[AssortedUtil](https://github.com/AssortedMods/AssortedUtil); see its README for building and
reporting issues.
