# Assorted Time

Press H for Grim Util's clock panel. Press again to step through the time in the world, the time
where you are, both, and hidden. Client-side, so it works on any server. From the Grim Util part of
the old [Grim Pack](https://github.com/grim3212/grim-pack).

Settings - a 24 hour or AM/PM clock - are in `assortedtime-client.toml`.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib). One of the mods built from
[AssortedUtil](https://github.com/AssortedMods/AssortedUtil); see its README for building and
reporting issues.
