# Assorted Util

Adds small helpers that make everyday Minecraft a little easier. This includes Assorted Graves, Assorted Double Doors,
Assorted Item Replacer, Assorted Time, Assorted Light Overlay and Assorted Damage Numbers in one download.

If you only want some of them you can install those mods on their own instead.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
