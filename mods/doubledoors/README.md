# Assorted Double Doors

Opening one door of a double door opens the other one too. It also works for groups of trapdoors and fence gates. Sneak to open just one.

Part of [Assorted Util](../../README.md).

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
